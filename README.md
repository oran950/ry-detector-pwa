🔊 Local Loud Audio Detector – Browser-Based
This project is a fully local web application that detects loud crying or screaming in audio files, running entirely in the browser with no backend or server required. Originally built in Python using librosa, it has been rewritten in JavaScript for mobile-friendly, offline use as a Progressive Web App (PWA).

🔹 Features:

Detects loud sounds (like crying or screaming) that persist for over 5 seconds.

Visual timeline showing detected loud segments.

Works directly in the browser on mobile or desktop – no file upload to servers.

Optimized for fast and private offline use.

🔧 Technologies:

JavaScript (AudioContext API)

HTML/CSS for responsive UI

Optional: Python librosa version for comparison and testing
